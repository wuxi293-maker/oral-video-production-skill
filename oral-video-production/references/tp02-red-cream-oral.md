# TP02｜红米口播版

> 编号 TP02 · 模板版本 v1.1 · 状态 active  
> 红底细白框 + 米色大圆角卡片 + 黑色媒体窗 + 红字幕条 + 蓝粉笔刷标题。

## 1. 适用

- 口播、访谈、品牌故事、前后对比、观点表达。
- 20–60 秒竖屏口播片。
- 需要“可翻阅的叙事卡”感，而不是资讯快讯。

不适合：高密度数据、公告截图、一屏多图对比。

## 2. 画布

| 项目 | 规格 |
|---|---|
| 画布 | 1080×1920 |
| 帧率 | 30fps |
| 码率 | 目标 12Mbps |
| 音频 | AAC 192k |
| 封面 | 3:4，1080×1440 |

## 4. 色彩与字体

| 角色 | 色值 |
|---|---|
| 外框红 | `#C51E24` |
| 米色卡底 | `#EDE6DA` |
| 黑媒体窗 | `#050403` |
| 字幕条红 | 亮红渐变，接近 `#D92B2B` |
| 标题蓝笔刷 | `#6FBBF5` |
| 标题粉笔刷 | `#FF9BE0` |
| 正文黑 | `#151515` |

- 中文：`Noto Sans CJK SC` Black 900。
- 标题第一行约 116px，第二行约 82px；按字数自适应，不溢出 870px。
- 字幕 35px；重点提示主字 40–54px，辅助字 20–24px。

## 5. 标题与笔刷

固定两行（样例）：

- 第一行：`一百年`，116px，蓝笔刷 `#6FBBF5`。
- 第二行：`中国从求人变成被求`，82px，粉笔刷 `#FF9BE0`。

实现：SVG 有机路径 + `feTurbulence` 位移做毛边，再叠一层半透明同色路径。标题左对齐，片内不变；跨片按脚本替换，删去非必要标点。

## 6. 镜头

- 不固定单镜时长；按语义和语音停顿切，单镜可 0.8–2.9 秒。
- 样例：24 镜 / 33.6 秒，12 条视频 + 12 张图片，平均约 1.4 秒一镜。
- 图片 Ken Burns：缩放约 1.035→1.11，配合 0–5px 平移；按单镜时长计算进度。
- 视频用 `OffthreadVideo`，`offset` 跳过片头；统一 30fps CFR。
- 默认硬切；只在章节/时空跳点加转场。

## 7. 转场

样例 23 个切点只挂 9 个：

| 切点 | 类型 | 帧数 |
|---|---|---|
| 42 | fade | 10 |
| 126 | wipeLeft | 12 |
| 234 | fade | 10 |
| 304 | push | 10 |
| 518 | fade | 12 |
| 604 | slideLeft | 12 |
| 709 | wipeUp | 10 |
| 770 | blur | 14 |
| 895 | push | 9 |

- `slide` 不叠透明度，避免双曝光。
- `wipe` 用外层 `clipPath`，让前一镜头从缺口露出。
- `push` / `blur` 带轻微缩放和虚实变化。
- 转场是章节标点，不逐切点加。

## 8. 字幕与重点提示

**底部整句字幕**

- 红条常驻，只换文字，不逐句出现/消失。
- 文字瞬时切换；不要给底部整句字幕做透明度淡出/淡入，否则每个句界会出现空白帧。
- 按词级时间戳切句；一句可以跨镜头，不要为了卡镜头拆句。
- 约 20 条/30 秒；每条停留足够读完。

**素材内重点提示**

- 三种样式：`tag`（小标签 + 主词 + 辅助）、`date`（日期/地点）、`statement`（结论句）。
- 四种入场：`mask`（左揭开）、`pop`（缩放弹入）、`slide`（上滑淡入）、`blur`（虚实聚焦）。
- 样例 12 条，每条 1.5–4 秒，卡在对应词前后。
- 同时最多 1 条；不遮挡人脸/产品主体；不与底部字幕完全重复。

## 9. 声音

- 人声先去气口，再整体提速；样例 `atempo=1.2`，保持音高。
- 处理链：`highpass=52`、`lowpass=14500`、`alimiter=0.95`，48kHz 单声道。
- BGM 用抖音热门曲，不用 AI 生成；增益约 0.20。
- 音效只在段落节点：样例 6 处，whoosh / impact 轮换。
- 成片长度跟处理后的人声。

## 10. 数据结构

```ts
type Shot = {
  id: string;
  kind: "image" | "video";
  src: string;
  start: number;
  end: number;
  tone?: "mono" | "paper" | "color";
  position?: string;
  zoom?: [number, number];
  pan?: [number, number, number, number];
  offset?: number;
};

type Transition = {
  kind: "fade" | "slideLeft" | "slideUp" | "wipeLeft" | "wipeUp" | "push" | "blur";
  frames: number;
};

type Callout = {
  start: number;
  end: number;
  kicker: string;
  main: string;
  trail?: string;
  style?: "tag" | "date" | "statement";
  enter?: "mask" | "pop" | "slide" | "blur";
};

type Caption = {start: number; end: number; text: string};
```

`transitions` 只写需要转场的切点；`callouts` 控制素材内重点提示；`captions` 控制底部整句字幕。

## 12. 样例已知问题

- v1/v2 的 `Subtitle` 对每条字幕做 4 帧淡入、3 帧淡出；每个句界会出现 1 帧空白。`qc_captions.py` 在 v2 检出 20 段低文字帧（19 个句界 + 末帧）。新片不要复刻：底部整句字幕应底板常驻、文字瞬时换字，不做逐句淡出/淡入。
- v2 的 `freezedetect` 可能在静图慢推段报冻结；回帧确认是 Ken Burns 误报，不是真冻结。
- 样例 BGM 用 Mixkit《Close Up》临时铺底；正式版按“抖音热门曲、不用 AI”的规则替换。
